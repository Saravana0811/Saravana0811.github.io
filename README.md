# Dr. Saravanakumar Duraisamy — personal website

A responsive research portfolio for AI, biomedical engineering and neurotechnology.

Public address: https://saravana0811.github.io/

## Maintain the site

- `index.html`: biography, education, experience, research, publications and links.
- `style.css`: responsive visual design.
- `script.js`: publication filters, mobile navigation and illustrative signal animation.
- `assets/`: university portrait, generated neural illustration and favicon.
- `ASSETS.md`: asset attribution and the illustration prompt.

No package installation or build is required. GitHub Pages serves the root of the `main` branch. Updates pushed to that branch are published automatically once Pages is enabled.

For a local preview, run `python3 -m http.server 8765` in this directory and open http://localhost:8765/ .
